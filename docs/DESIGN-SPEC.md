# Pendant 設計規格（給 Windows 版對照用）

這份文件把 macOS 版 Pendant 的尺寸、動畫、版面與行為整理成數字與規則，讓 Windows 版不是「憑感覺做」，而是照規格做、再用並排截圖比對。數值來自 `Pendant/Core/Tuning.swift`、`CapsuleLayout.swift`、`NotchGeometry.swift`、`AnimationTokens.swift` 與各模組的程式；macOS 版若改了，請以程式碼為準並更新這份文件。

單位一律是「點」（pt）：macOS 的 1 pt 在 Windows 對應「與裝置無關的像素」（DIP，100% 縮放下 1 DIP = 1 px）。

## 1. 「一模一樣」的範圍

| 層級 | 說明 | Windows 版目標 |
|---|---|---|
| A. 版面與尺寸 | 每個狀態的寬高、圓角、間距、文字大小與位置 | 要一致 |
| B. 動畫手感 | 彈簧參數、模糊／淡入／縮放的時間與延遲 | 要一致（用下方換算） |
| C. 行為與流程 | 何時展開、何時收起、點哪裡做什麼 | 要一致 |
| D. 文案 | 繁體中文的所有文字 | 要一致 |
| E. 質感與系統整合 | 字體、液態玻璃、觸控板觸覺、AirDrop、蘋果的行事曆／提醒事項 | 無法一致，見 §10 |

## 2. 幾何與外形

- **瀏海本體**：靠螢幕上緣、水平置中。有實體瀏海的螢幕用系統回報的寬高；沒有的（虛擬瀏海，Windows 一律是這種）寬 185、高 = 選單列高度（至少 32）。可再加使用者微調（設定「實體瀏海寬度微調」，預設 0，範圍−30…+30）。
- **反向圓角（耳朵）**：外形比本體左右各寬 8 pt；上緣兩側是向內凹的四分之一圓（半徑 8），讓膠囊像是從螢幕上緣長出來。
- **底部圓角**：閒置 10（滑過 12）、小膠囊 12（膨脹 14、顯示歌名 22）、展開 26、HUD 12（膨脹 14）、提示卡片 28。
- **懸停觸發區**：本體外擴 3 pt，並一直延伸到螢幕最上緣。
- **外形程式**：`NotchShape`（`Pendant/App/NotchShape.swift`），路徑：左上耳朵 → 左側下降 → 左下圓角 → 底邊 → 右下圓角 → 右側上升 → 右上耳朵。

## 3. 狀態與尺寸

| 狀態 | 寬 | 高 |
|---|---|---|
| 閒置 | 瀏海寬（虛擬瀏海：同小膠囊寬，因為要放時間與電量） | 瀏海高 |
| 小膠囊 | 瀏海寬 + 2 × 翼寬 | 瀏海高 |
| 展開 | 依模組格數，見 §6 | 瀏海高 + 內容高度 190 + 下方留白 6 |
| 音量／亮度 HUD | 瀏海寬 + 2 × 100 | 瀏海高 |
| 提示卡片（虛擬瀏海） | 340 | 56 |
| 提示卡片（實體瀏海） | 瀏海寬 + 2 × (瀏海高 + 44) | 瀏海高 + 44 |

- **翼寬（小膠囊）** = 瀏海高 + `wingExtra`（0）+ 計時器多出的位置；虛擬瀏海下至少 50 + `wingExtra`。
- **膨脹（滑過）**：寬 × 1.08、高 × 1.22。顯示歌名／計時結束通知時，再加高 28（歌名一行）或 46（計時通知兩行）。
- 螢幕左右邊至少留 24 pt；模組太多時每格縮小以放進螢幕。

## 4. 動畫

SwiftUI 的 `spring(response: r, dampingFraction: ζ)` 換成物理彈簧（質量 m = 1）：

- 勁度 `k = (2π / r)²`
- 阻尼 `c = 4π · ζ / r`

例：展開 r = 0.5、ζ = 0.58 → k ≈ 157.9、c ≈ 14.6。其他框架（CSS／Framer Motion／WinUI 的 NaturalMotion 彈簧）用同一組 `k, c, m` 或其對應參數。

| 名稱 | response | damping | 用途 |
|---|---|---|---|
| expand | 0.50 | 0.58 | 展開 |
| collapse | 0.32 | 0.85 | 收起 |
| hoverSwell | 0.30 | 0.50 | 滑過膨脹（有點彈） |
| unswell | 0.28 | 0.92 | 膨脹收回（幾乎不過衝） |
| island | 0.42 | 0.74 | 副島分開／合併／升級 |
| HUD 展開 | 0.34 | 0.78 | 音量／亮度膠囊長出 |
| HUD 收回 | 0.36 | 0.85 | |
| 卡片展開 | 0.40 | 0.76 | 充電／低電量／藍牙卡片 |
| 卡片收回 | 0.38 | 0.86 | |
| HUD 滑過 | 0.30 | 0.55 | HUD 本身膨脹 |
| 減少動態效果 | easeInOut 0.15 s | | 系統開了「減少動態效果」時，全部改用這個 |

**內容換場（RevealEffect）**：進場 = 模糊 12 → 0、不透明度 0 → 1、縮放 0.94 → 1（錨點上緣），easeOut 0.28 s，加上延遲（HUD／卡片 0.10 s、展開內容 0.10–0.14 s）；離場 = 模糊、淡出、縮小，easeIn 0.12 s，無延遲。大塊內容離場只淡出不模糊（避免卡頓）。

**擠換（SqueezeSwap）**：兩塊內容在同一位置互換，離場那塊先模糊淡出縮小（0.12 s），進場那塊延遲 0.14 s 再模糊淡入放大（0.28 s）。用在待辦事項頁的「清單 ⇄ 新增待辦」。

**HUD 與卡片**：是膠囊自己的形狀變形（不是另一個視窗）：形狀寬／高用彈簧長到目標大小，內容用 RevealEffect 顯示；原本的小膠囊內容同時模糊淡出。顯示時間：HUD 1.6 s、卡片依設定。

**單獨頁（focus）轉場**：同一個畫面在小工具頁與單獨頁之間平移（播放器是同一個視圖，不是換一個），轉場 0.9 s 內暫停懸停效果（封面不會卡在 3D 傾斜）。

## 5. 互動規則

- **滑過瀏海**：閒置或小膠囊 → 膨脹（hoverSwell），不立刻展開；懸停展開預設關閉（設定可改成滑過 0.3 s 展開）。
- **點擊**：點小膠囊或瀏海 → 展開（回到該活動的頁面）。
- **收起**：滑鼠離開後延遲 0.3 s 收起；有彈出視窗（popover）或單獨頁（預設）時不收；點膠囊外面立刻收。
- **展開後頂端**：左上角是分頁切換（小工具／筆記／檔案中轉站）；單獨頁時換成「< 返回 | 標題」，點整個區塊返回。
- **觸覺回饋**：Mac 專屬（觸控板）。碰到瀏海、展開開始、收起完成、拖曳跨過一格、計時結束都有；**滑到按鈕上不震動**。Windows 版沒有此項（除非硬體支援，不做也可以）。

## 6. 展開面板與模組

- **格寬 72**、左右內距 18、模組間距 30、分隔線長度 = 內容高度 × 0.88、內容高度 190、下方留白 6。
- 預設模組與格數：媒體播放器 5、筆記 6、待辦事項 4、行事曆 5、計時器 4（3–6）、鏡子 2、檔案中轉站 6、捷徑 4。
- 預設分頁：「小工具」＝媒體、待辦、行事曆、計時器、鏡子、捷徑；「筆記」；「檔案中轉站」。
- 面板寬度 = 各模組格數 × 格寬 + 間距 + 內距，上限是螢幕寬減 48。

### 媒體頁
封面 118、封面與文字間距 12、標題 17、專輯／歌手 14、控制列間距 8、上一首／下一首圖示 15、播放圖示 23、按鈕寬 26、進度條細 4／粗 8（拖曳時）。上方內距 12、下方 8、封面列與進度條間距 6。單獨頁：左邊播放器（最寬 5 格或 56%）、右邊同步歌詞（目前行白色置中，其他淡 0.32）。

### 行事曆
月份字 22；日期條高 54，每日間隔 42，焦點日期字 26、其他 15，焦點兩側留白 10；單獨頁日期條填滿整個寬度、今天放在寬度的 15% 處、遠處日期不模糊；活動磚寬 210、高度由內容決定（至少約 42），由左到右排列。

### 待辦事項
標題「待辦事項」20 粗體，右上：「＋」按鈕、未完成數量徽章；按＋以擠換切換成新增待辦框（再按變 ×）。清單依分類分組，分類標題捲動時置頂；單獨頁左清單、右新增框。

### 計時器
倒數與碼錶；按鈕 36（圓形）、邊距 8、與分隔線距離 4。計時結束：膠囊閃白框、播放聲音、顯示通知。

### 檔案中轉站
抽屜與 AirDrop 兩區；拖著檔案進來時兩區改顯示「放開即可加入檔案抽屜／放開即可 AirDrop」，停在某區上方該區放大，放下後抽屜掃過一道由上到下的亮光。Windows 版沒有 AirDrop（可改成「附近分享」或拿掉）。

## 7. 虛擬瀏海（沒有實體瀏海的螢幕）

- 分三塊：左（電量：圖示或圓環，可加百分比）、中（時間，可帶日期與秒數）、右（目前為空）。閒置時中間寬 128、左右翼各 50。
- 活動出現時（音樂／計時／檔案）：左右內容模糊淡出，活動的圖示淡入。
- 展開時頂端中間的條：電量、日期、時間可各自開關。
- 螢幕進入 macOS 全螢幕時隱藏（Windows 版對應「有全螢幕應用程式」時隱藏）。

## 8. 顏色與字

- 膠囊一律純黑 `#000000`；文字白色，次要文字白色 50–60% 不透明。
- 提示色：綠 `rgb(48, 214, 115)`（充電）、紅 `rgb(255, 69, 59)`（低電量）、藍 `rgb(64, 166, 255)`（藍牙）。
- 字：標題 17–22 粗體，內文 12–15，次要說明 10–12.5；macOS 用系統字體，Windows 版請用接近的字（例如 Segoe UI Variable 或思源黑體），粗細與大小照上面。

## 10. 在 Windows 上無法一致、需要替代的項目

| macOS 版 | Windows 版建議 |
|---|---|
| 實體瀏海對齊 | 沒有瀏海，一律當虛擬瀏海：頂端置中浮動膠囊 |
| Liquid Glass（設定視窗、玻璃側欄） | 壓克力／Mica 近似；或純色半透明 |
| 觸控板觸覺 | 略過 |
| Apple Music／Spotify（AppleScript） | 系統媒體控制（SMTC）取得目前播放、控制播放；歌詞照樣用 lrclib |
| 行事曆（EventKit） | Outlook／Microsoft 365 日曆（Graph API）或本機 `.ics`，需另外決定 |
| 提醒事項（EventKit） | Microsoft To Do（Graph API）或本機清單，需另外決定 |
| AirDrop | 附近分享或拿掉 |
| 系統音量／亮度鍵攔截（輔助使用權限） | 低階鍵盤攔截或監聽音量變化（WASAPI），亮度用 WMI |
| 鏡子（相機） | Windows 相機 API（MediaCapture） |
| 登入時啟動 | 開始資料夾或登錄檔 Run |
| 自動更新（本機資料夾 / GitHub） | 可沿用 GitHub Releases 的格式與簽章驗證做法 |

## 11. 驗證方式

1. 兩邊各自在同一個狀態截圖（閒置、小膠囊、展開、HUD、三種卡片、日曆／待辦／音樂的小工具頁與單獨頁、設定各頁），並排比較，列出差異。
2. 動畫：同一段操作錄影，兩邊抽格比較展開／收起／擠換的時間與過衝。
3. 差異清單：每項標「一致／因系統限制不同／待補」。
4. 截圖只裁切膠囊區域，不要留下含其他視窗或個人資料的畫面。
